# Healthcare EMR & Clinical Management System

A comprehensive, full-stack Electronic Medical Record (EMR) system designed for modern healthcare facilities. Built with a focus on deep architectural correctness, security, and scalability.

## 🚀 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Database:** PostgreSQL / MySQL via Prisma ORM
- **Styling:** Tailwind CSS & Shadcn UI
- **Validation:** Zod (Strict Schema Validation)
- **Icons:** Lucide React

## ✨ Key Features

- **Multi-Role Portals:**
  - **Admin:** Management of providers, patients, and system-wide analytics.
  - **Provider (Doctor):** Patient assignments, clinical assessments, and visit history tracking.
  - **Patient:** Appointment booking, medical record access, and billing management.
- **Appointment System:** Real-time scheduling with dynamic status updates.
- **Secure EMR:** HIPAA-aligned architecture for sensitive medical data handling.
- **Clinical Dashboard:** Visual analytics for doctors and administrators.
